### Reproduction detail

The database-free admission check instantiates `ResearchAdmission`, substitutes `prepare` with a prepared operation, makes `usage.reserve` append `reservation committed` and return its reservation ID, and makes `jobs.accept` raise `psycopg.errors.InsufficientPrivilege`. Spies on `close` and `reconcile_release` remain untouched. The command asserts the event list is exactly `["reservation committed"]` and prints `REPRODUCED: reservation committed; authority denial escaped; no closure or release`.

The exception is grounded in the actual dependency: `ResearchRepository.run` invokes `backend.transactions.guard`, which calls `accounts.guard_session`; `backend/modules/accounts/u3_session_authority.sql` rejects revoked, expired and authority-mismatched sessions with SQLSTATE 42501. Usage reservation and research acceptance each invoke this guard in separate committed transactions. The existing closed-admission fault test revokes authority only after closure and therefore does not exercise this interval.
